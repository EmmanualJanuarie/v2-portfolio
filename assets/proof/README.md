# Project proof media

Add public-safe screenshots or video recordings in a folder for each project:

- `udes/`
- `azure/`
- `networking/`
- `windows-server/`
- `cloud-security/`

Register each file in the matching project's `media` array in the root `proof.js` file. Supported types are `image` and `video`. Do not include credentials, personal information, customer records, or sensitive infrastructure details.
